# Paper workspace

This directory will contain an ICASSP-format source tree, reproducible figures,
verified bibliography, compiled PDF, narrative history, and peer-review bundles.
No table cell or citation is added without a source artifact. The author block
uses explicit placeholders until authorized metadata is supplied. ICASSP 2027
uses single-anonymous review, so the placeholders must be replaced before
submission; read `AUTHOR_BLOCK_REQUIRED.md`.

The paper begins from the provisional causal-audit narrative and is permitted to
pivot only after a documented outer-loop reflection.
