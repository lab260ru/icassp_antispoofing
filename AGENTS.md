# Writing and editing rules for this repository

Rules any agent or person editing paper prose here must follow. The user has
asked for these explicitly; do not relax them without asking.

## Prose style

- **No em-dash parenthetical constructions.** Never write
  "text --- explanation --- text". Restructure with a comma, colon,
  semicolon, parentheses, or a second sentence. En-dashes for numeric
  ranges (34.4--86.4) are fine; table empty-cell dashes are fine.
- **No "stimuli".** Say "test set", "items", or "sentences".
- **No "benchmark"** for our data (overclaims); say "test set".
- **No "rung"**; say "step" (of the period ladder).
- **Short paragraphs.** Split anything over ~6 sentences.
- **Bold run-in headers** for setup/discussion paragraphs
  (\noindent\textbf{Name.}), one topic each.
- **Abstracts open with the phenomenon, not the apparatus**, define any
  term of art they use (e.g. what a "control" is), and stay under ~155
  words.
- Prefer a table over a sentence packed with numbers; every table that
  names a model cites it.

## Numbers

- **Never hand-type a measured number** in any .tex file. Every measured
  value is a macro from numbers.tex (generated by analysis/make_numbers.py).
  Design constants (k ladder, page limits) are exempt.

## Structure

- `paper/` outside `paper/ICASSP_paper/` is the **frozen submitted record**
  (tag v2.2-isolating). Do not edit it. All rewriting happens in
  `paper/ICASSP_paper/main/` and `paper/ICASSP_paper/supplement/`.
- The main text carries **no supplement section pointers** (no "(S14)");
  refer to "the supplementary material" generically.
- Nothing stated in the main paper is restated in the supplement; the
  supplement holds detail the main text points to, not copies of it.
- The rewrite is **anonymous**: no author names, no repository URLs, no
  "companion paper" phrasing; own prior work is cited in third person.

## Fonts (tectonic + spconf)

spconf sets Times via `\rmdefault{ptm}`, and this machine's tectonic bundle
maps every ptm shape (regular, bold, italic) to LMRoman-Regular. Result: a
paper that compiles green with NO bold or italic anywhere, silently. The
submitted paper shipped that way. The rewrite loads
`\usepackage{newtxtext,newtxmath}` after spconf, which embeds TeX Gyre
Termes (a true Times clone) with working weights. Never remove those two
packages; if fonts look uniform-weight in a render, suspect this first.

## Supplement conventions (paper/ICASSP_paper/supplement/)

- Numbers in the supplement are hand-typed literals by long-standing project
  convention (it does not load numbers.tex); the macros-only rule applies to
  the main paper. When results regenerate, the supplement's numbers must be
  re-checked by diff, not assumed.
- The supplement contains no code, no file paths, no package pins, no commit
  hashes; methods are described in words and the Release section says the
  artifacts are pinned. The formal result appears as ordinary mathematics
  with proofs; Lean is mentioned only in the machine-verification note.
- The rewritten supplement is assembled from parts/p01..p09 by supp.tex;
  edit the part files, not the assembled build. The pre-rewrite snapshot is
  supp_v22_snapshot.tex (do not edit it).
