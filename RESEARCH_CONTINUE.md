## Decision experiment 1: Jacobian q estimator (Track A gate) — ~0.5 day

Two attempts failed; **do not repeat them** (see "already failed" below). The
untried approach both failures point to:

- Estimate the **top singular value of the boundary-to-boundary Jacobian** via
  `torch.autograd` JVP/VJP power iteration, teacher-forcing the generated
  token sequence so the map is well-defined. Exact directional derivatives
  remove the finite-difference step-size problem that killed attempt 2 (its
  linearity control failed). Boundaries: use the *known token spans of each
  repetition in the teacher-forced input* — you do not need the non-monotone
  attention read-head that killed attempt 1, because in a teacher-forced pass
  you know exactly which token positions each repetition occupies.
- Llasa-1B first (16 layers, cheapest; activations + tokens already on HDD at
  `/home/kirill/mnt/hdd_6tb_1/icassp_tts/`). Compare repeated vs control items,
  per layer, per lag. `analysis/contraction_probe.py` has the hook machinery
  and the self-test pattern to copy; `pooled_q.py` has the pooling/bootstrap.
- **Pre-commit the interpretation**: q<1 on repeated ≠ control → Track A alive;
  q≥1 or repeated ≈ control → the theorem premise is dead in this decoder and
  you say so and pivot. Write the verdict logic into the script before seeing
  results (house style — see `probe_past_horizon.py`).

## Decision experiment 2: activation-patching pilot (Track B gate) — ~0.5 day

Nothing causal has ever been run on the states. The gold-standard mech-interp
experiment, cheap at Llasa-1B scale:

- **Patch**: run a repeated item (k=16/24/32), teacher-force; at matched
  positions, splice in hidden states from (a) the same item at a *different k*,
  or (b) its control. Resume generation. Does the rendered count follow the
  donor? A count that moves with the patch is a causal locus.
- **Steer**: build a "count direction" per layer (difference-in-means of states
  across k, or the ridge probe's weight vector from `analysis/probe_count.py` —
  probes already trained, activations already exist for 10 model variants,
  ~140 npz each). Add ±α·v during generation; measure rendered-count shift
  with the standard CTC pipeline (`src/common/asr_ctc.py` + `score_counts.py`).
- Even a *null* here is publishable in Track B ("the count is linearly
  decodable but not causally used — the stop decision reads X instead"), which
  dovetails with the F5-TTS `fix_duration` result (duration fixes k<12
  failures fully, k≥12 not at all — `analysis/duration_intervention.py`).

## Definition of a strong paper (pick the one your track earns)

- **A**: "We prove the bound *and measure its premise*: q = 0.xx [CI] on N
